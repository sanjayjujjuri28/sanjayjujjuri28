# 🚀 Featured Projects

## 🔥 HookRelay

### Webhook Delivery & Reliability Platform

**HookRelay** is a production-style webhook platform built to understand how real backend systems handle asynchronous events, retries, failures, authentication, and delivery tracking.

### 🧠 Architecture

```text
Client
   ↓
FastAPI API
   ↓
PostgreSQL
   ↓
Background Worker
   ↓
HTTP Webhook Delivery
   ↓
External Endpoint
```

### ⚡ Key Features

- RESTful API using FastAPI
- Webhook registration
- Event-based webhook delivery
- HMAC signature generation
- Secure webhook verification
- Asynchronous/background processing
- PostgreSQL database
- SQLAlchemy ORM
- Alembic database migrations
- Delivery status tracking
- Delivery logs
- Failure handling
- Automatic retries
- 3 delivery attempts
- Exponential backoff
- HTTP response tracking
- Pending / Success / Failed states
- Fresh database sessions for background workers
- Production deployment

### 🧰 Technologies

```text
FastAPI
PostgreSQL
SQLAlchemy
Alembic

HMAC

```
